                         CURRENT MODEL RESULTS
================================================================================

Final Model Selected: Random Forest Classifier
Selection Basis: Best overall performance in the final held-out test evaluation
                 and highest 5-fold cross-validation accuracy among the models
                 evaluated in the latest reproducible notebook run.

Dataset:
  • Source: UCI Heart Failure Clinical Records dataset
  • Total records: 299 patients
  • Input features: 12 clinical/demographic variables
  • Target variable: DEATH_EVENT
  • Missing values: 0
  • Class distribution: 203 no-event records (67.89%), 96 event records (32.11%)

Final Held-Out Test Set Results (test_size=0.20, random_state=42, stratify=y):
  • Accuracy:       83.33%

  • Recall:         63.16%
  • F1-score:       70.59%
  • ROC-AUC:        0.8909
  • Test-set size:  60 records

Important methodological limitation:
  • The time variable represents follow-up duration. It is highly predictive in
    this dataset but may not be available at an initial patient assessment.
  • A future baseline-risk model should evaluate performance without time to
    avoid possible temporal/data leakage.
  • Feature importance is model-specific and does not establish clinical
    causality.

================================================================================
                            PROJECT LIMITATIONS
================================================================================

  • Small dataset: 299 records only.
  • Single-source clinical dataset; results require external validation.
  • Dataset class distribution is imbalanced (67.89% no event vs 32.11% event).
  • Current evaluation is based on one held-out test split plus cross-validation.
  • The time feature may cause temporal leakage for initial risk prediction.
  • The model is not clinically validated and must not be used in healthcare
    decisions.
  • Performance can vary across splits, populations, data quality, and feature
    availability.
