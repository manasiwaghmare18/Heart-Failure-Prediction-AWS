# Heart Failure Prediction with Machine Learning
## Key Project Description (4 Lines)

**Aim:** Develop a machine learning classification system to predict heart failure occurrence in patients using clinical measurements and medical history data.

**Methodology:** Analyzed 299 patient records with 13 clinical features using exploratory data analysis, data preprocessing, and seven different classification algorithms (KNN, Logistic Regression, Decision Tree, Random Forest, Gradient Boosting, SVM, Naive Bayes) with 5-fold cross-validation.

**Results:** Achieved 85.55% accuracy with K-Nearest Neighbors (KNN) algorithm, outperforming six other models with excellent generalization (85% ± 3.14% cross-validation). Identified ejection fraction, serum creatinine, age, and serum sodium as key predictive features accounting for 85% of prediction power.

**Impact:** Provides clinical decision support for early heart failure detection, enabling identification of high-risk patients for preventive interventions and supporting personalized medicine approaches in healthcare settings with comprehensive documentation for academic and professional deployment.
